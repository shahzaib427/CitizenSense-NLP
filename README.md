# CitizenSense - NLP-Based Public Feedback Classification and Insight System
AIRI Team PITB - AI Internship Task 4 (Option A + Roman Urdu extension)

Takes a short complaint/feedback message (English, Roman Urdu or mixed) and returns **category, sentiment, priority, keywords, summary, suggested department/action, confidence** and a human-review flag.
> Learning prototype. Predictions are suggestions, not decisions.

## Data (IMPORTANT)
The dataset is **100% synthetic**: generated by `scripts/01_generate_synthetic_data.py` from hand-written phrase banks, with injected noise (URLs, phone numbers, typos, duplicates). No real citizen data or personal information is used.
- Raw rows 1,512 -> **1,251 after cleaning** (8 categories, 3 sentiments, 4 priorities), split 70/15/15 stratified (875 / 188 / 188).
- `data/manual_review_sheet.csv`: 220 rows for **you to verify/correct by hand** (the brief requires 200+ manually labeled samples). Put your own hand-written rows in `data/raw/manual_*.csv` (`text,category,sentiment,priority`) and re-run the pipeline.
- `data/raw/challenge_set.csv`: 49 free-form hand-written messages kept **out of training** to measure realistic performance.

## Quick start
```bash
pip install -r requirements.txt
python scripts/01_generate_synthetic_data.py   # raw data
python scripts/02_clean_and_split.py           # clean, dedupe, encode, split
python scripts/03_train_baseline.py            # train/compare models, metrics, plots, error analysis
python scripts/04_challenge_eval.py            # realistic generalisation check
python app/demo.py                             # CLI demo
streamlit run app/streamlit_app.py             # Streamlit demo (+ batch CSV, charts)
uvicorn app.api:app --reload                   # FastAPI: POST /analyze-feedback
```
Open `notebooks/nlp_feedback_analysis.ipynb` for the full walkthrough (outputs included).

## Models
- **Baseline:** TF-IDF (word 1-2 grams + char 2-5 grams) with Naive Bayes, Logistic Regression, calibrated Linear SVM, Random Forest. Best per task chosen on **validation** macro-F1; test set untouched until reporting.
- **Transformers (`app/hf_models.py`):** zero-shot classification (BART-MNLI), multilingual sentiment (XLM-R), summarisation (DistilBART), multilingual MiniLM sentence embeddings + Logistic Regression. These need internet; run the notebook's section 7 in **Colab** and record your numbers.
- **Keywords:** TF-IDF scores + domain-lexicon boost + bigram phrases. **Summary:** template-based extractive (offline); optional HF summariser for long text.

## Results (from `outputs/`)
| Task | Selected model | Template test split | Hand-written challenge set |
|---|---|---|---|
| Category (8 classes) | Calibrated Linear SVM | Acc 0.995 / macro-F1 0.995 | Acc 0.592 / macro-F1 0.551 |
| Sentiment (3) | Logistic Regression | Acc 1.00 | Acc 0.898 / macro-F1 0.731 |
| Priority (4) | Logistic Regression | Acc 0.787 / macro-F1 0.784 | Acc 0.429 / macro-F1 0.385 |

**Read this honestly:** the near-perfect template score is optimistic because train and test are generated from the same phrase banks. The challenge-set score is the realistic estimate. Weakest on the challenge set: Traffic, Water Supply, Roads (short, unseen wording, multi-issue text). Neutral/Positive classes are small, so sentiment metrics are unstable.

## Limitations
Synthetic data; Roman Urdu spelling varies a lot; no multi-label support; priority labels are rule-derived, not expert-assigned; the danger-word rule can over-escalate; not for real government decisions.
